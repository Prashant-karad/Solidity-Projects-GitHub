# Solidity Projects

A beginner-friendly Solidity project containing two smart contracts:

- `MyBank.sol` — deposit Ether, withdraw Ether, and check balances.
- `StudentData.sol` — add student records and read student details.

## Project structure

```text
Solidity-Projects/
├── contracts/
│   ├── MyBank.sol
│   └── StudentData.sol
├── .gitignore
└── README.md
```

## Compile and run in Remix

1. Open https://remix.ethereum.org/
2. Clone this GitHub repository into the Remix workspace using the Git / Clone Git Repository feature, if available in your Remix setup.
3. Open `contracts/MyBank.sol` or `contracts/StudentData.sol`.
4. Open the Solidity Compiler tab and select a compatible compiler:
   - MyBank: Solidity 0.8.x
   - StudentData: Solidity 0.8.20 or newer
5. Compile the selected contract.
6. Open Deploy & Run Transactions, select the contract, and deploy it using Remix VM.

If your Remix workspace does not show a Git clone option, use the Git plugin from Remix's Plugin Manager, or use the GitHub import feature / upload the two `.sol` files.

## MyBank quick test

- Deploy `MyBank` with Value = `1` and unit = `Ether` (optional).
- Call `viewBalance()` to see the caller's recorded balance in Wei.
- Set Value = `2 Ether` and call `deposit()`.
- Call `withdraw(1000000000000000000)` to withdraw 1 ETH. Keep Value = 0.
- Call `bankBalance()` to see the Ether held by the contract in Wei.

Important:
- `deposit()` is payable, so set the Ether amount in Remix's Value field.
- `withdraw(amount)` takes the amount in Wei as its function argument. Do not send Ether in the Value field when calling it.
- `viewBalance()` shows the balance recorded for the currently selected caller account.

## StudentData quick test

Call `addStudent` with example values:

- `_rollNo`: `1`
- `_name`: `"Amit"`
- `_age`: `20`
- `_course`: `"Computer Engineering"`

Then call:
- `getStudentCount()` — returns the number of stored students.
- `getStudent(0)` — returns the first student's details.
- `students(0)` — autogenerated getter for the first array entry.

## Notes

- These contracts are educational examples, not audited production contracts.
- `StudentData` allows anyone to add records; it has no access control or update/delete functions.
- `StudentData` can receive Ether through `receive()` and `fallback()`, but it has no function to withdraw that Ether.
